网络与 SNMP 协议（4 人共同语言，必须都懂）

这是全组的地基。答辩时四个人都会被问到，答不上来直接扣分。

必须搞懂的核心概念（自查清单）

  • SNMP 是管理者-代理模型：NMS 发查询，设备的 agent（snmpd）回数据
  • OID 是一串数字，像 .1.3.6.1.2.1.1.5.0 是设备主机名，本质是树形地址
  • MIB 是 OID 的"字典"，把数字翻译成人话（如 SNMPv2-MIB::sysName.0）
  • GET = 读一个值；WALK = 遍历一整棵子树；GETBULK = 批量高效读表
  • community（团体名） 类似密码，默认 public；SNMPv3 才有真正的认证加密
  • 常用 OID 记住几个：1.3.6.1.2.1.1.3.0（运行时长）、1.3.6.1.2.1.2.2.1.10（入站流量）、...1.16（出站流量）

命令行工具（现场演示会用到）

sudo apt install snmp            # Ubuntu / 树莓派装 Net-SNMP 工具
snmpget -v 2c -c public 192.168.1.10 .1.3.6.1.2.1.1.5.0      # 读一个 OID
snmpwalk -v 2c -c public 192.168.1.10 .1.3.6.1.2.1.1        # 走一整棵子树
snmpwalk -v 2c -c public 192.168.1.10 .1.3.6.1.2.1.2.2.1.10  # 走所有网口入站流量

三层防御话术（答辩命门，全员背）

文档原话"三层防御话术逐字背，这是答辩的命门。"
层级讲什么
第一层痛点 + 政策：校园网络设备故障发现慢、人工巡检成本高；对应国家的网络安全管理政策要求
第二层技术方案：SNMP 采集 → EMA 基线偏离检测 → 实时 Web 看板告警，闭环
第三层对比优势：静态阈值会误报/漏报，基线偏离能自适应；成本仅 ¥300-350，远低于商用网管系统
