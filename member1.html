01

EMA 指数加权移动平均（最核心）

EMA 就是你项目里"基线"的数学本体。公式只有一个：

Z_t = α · x_t + (1 - α) · Z_(t-1)
  • x_t = 当前这次采到的流量值
  • Z_t = 更新后的基线（平滑值）
  • α = 权重（0<α<1），决定"记性好不好"
    • α 小（0.1-0.3）→ 记得久、平滑、不敏感，但响应慢
    • α 大（0.5-0.9）→ 反应快、敏感，但容易被噪声带偏

你要看的资料

原理EMA 控制图原理讲得最清楚，含公式推导 对比EWMA vs CUSUM 对比（含参数怎么选） 统计EWMA 完整统计原理 + λ 选择表

B 站搜索：指数加权平均 讲解 · EWMA 异常检测 · 移动平均 平滑 通俗

吴恩达深度学习里的指数加权平均（讲得最通俗，B站有搬运）。

自查：能不能回答

  • 为什么 α 越小，基线越"迟钝"但越抗噪？
  • 基线一开始没有历史数据，Z_0 怎么初始化？（答：用前 N 个采样点的均值，或第一次采到的值）
  • 采样间隔对 α 的等效"记忆长度"有什么影响？记忆长度约等于 1/α 个采样点
02

迟滞判定 Hysteresis（防止告警抖动）

要解决的问题：流量在阈值线上下反复横跳时，如果直接比较就会疯狂误报。

// 伪代码：两个阈值，进去和出来用不同的线
if (当前值 > 高阈值 UPPER):  进入告警状态
if (当前值 < 低阈值 LOWER):  退出告警状态
// 在 UPPER 和 LOWER 之间时，维持之前的状态不变

文档里提到的 DROP_RATIO / RISE_RATIO 就是这两个阈值的系数。

本质硬件里叫施密特触发器，软件里叫迟滞，本质是同一个思想。B 站搜 施密特触发器 有大量生动动画。

自查

  • 为什么迟滞能消除抖动？画出流量曲线 + 两条阈值线，标出状态切换点
  • 如果 UPPER 和 LOWER 挨得很近会怎样？（答：退化成单阈值，失去防抖作用）
  • 现场调参时，把 DROP_RATIO 调大/调小分别会发生什么？（答辩要现场演示这个）

B 站搜索：迟滞比较器 原理 · 施密特触发器 通俗讲解 · 阈值 抖动 消除

03

锁存机制 Latch（告警状态保持）

要解决的问题：瞬时冲高又立刻回落，如果只看当前值就会"闪一下"就没了，看板和日志抓不住。

// 伪代码：一旦触发，锁定 N 个周期不释放
if (触发条件成立): latched = true; latch_countdown = N
if (latched):
    if (latch_countdown > 0): latch_countdown--
    else: latched = false    // 冷却结束才能重新判定

硬件里叫 SR 锁存器 / D 触发器，软件里叫告警锁存 / 冷却期（cooldown）。工业监控里叫 alarm latching / alarm suppression。

自查

  • 锁存和迟滞的区别是什么？（提示：迟滞管"阈值边界"，锁存管"时间持续"）
  • 冷却期设太长会有什么后果？（答：漏报后续真实异常）
  • 项目里锁存是为了让"看板上能看见告警"——这句话怎么理解？

B 站搜索：锁存器 原理 · SR锁存器 通俗讲解 · 告警 抑制 冷却时间

04

静态阈值 vs 基线偏离（你的对比实验）

这是答辩第 35-45 分钟的展示重点，必须能讲清楚为什么基线法更好。

维度静态阈值基线偏离（EMA+迟滞+锁存）
阈值人为定死，如"流量>100Mbps 告警"自动学习历史水平，自适应
白天/夜间差异无法区分，夜间误报基线自动跟随日常规律
网络扩容后阈值失效，要人工重设基线自动适应新水平
缓慢爬升型异常察觉不到累计偏离，能早期发现
成本低（但误报代价高）低（算法全免费）
对比实验图要画同一段流量数据上，静态阈值和基线偏离两种方法的告警时点对比。
英文EWMA 控制图 vs 常规控制图对比英文但权威
