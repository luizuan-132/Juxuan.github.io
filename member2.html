01

SNMP 协议基础（先看这个，2-3 小时）

不看协议直接抄代码，后面排障会完全懵。

必须掌握的（自查清单）

  • 报文交互流程：NMS 发 GET → agent 回 Response，UDP 161 端口
  • OID 树结构：iso(1) → org(3) → dod(6) → internet(1) → mgmt(2) → mib-2(1)
  • community 团体名 = 密码（默认 public），SNMPv2c 明文传输无认证
  • GET vs WALK vs GETBULK 的区别和适用场景

04

pysnmp 7.x async API（核心，4-5 小时）

🚨 最大的坑pysnmp 7.x 和网上 4.x 教程写法完全不同！7.x 用 asyncio 重写了，网上 90% 的中文教程还是 4.x 老写法，直接抄必然跑不起来。以官方文档为准。

① GET 单个 OID

import asyncio
from pysnmp.hlapi.v3arch.asyncio import (
    SnmpEngine, CommunityData, UdpTransportTarget,
    ContextData, ObjectType, ObjectIdentity, get_cmd, bulk_cmd
)

async def main():
    errorIndication, errorStatus, errorIndex, varBinds = await get_cmd(
        SnmpEngine(),
        CommunityData('public', mpModel=1),          # mpModel=1 → v2c
        await UdpTransportTarget.create(('192.168.1.10', 161)),
        ContextData(),
        ObjectType(ObjectIdentity('1.3.6.1.2.1.1.5.0'))
    )
    if errorIndication:
        print('传输错误:', errorIndication)
    elif errorStatus:
        print('SNMP错误:', errorStatus.prettyPrint())
    else:
        for name, val in varBinds:
            print(f'{name.prettyPrint()} = {val.prettyPrint()}')

asyncio.run(main())

② GETBULK 高效走表

# 读所有网口流量，性能远好于逐条 getnext
async for errorIndication, errorStatus, errorIndex, varBinds in bulk_cmd(
    SnmpEngine(),
    CommunityData('public', mpModel=1),
    await UdpTransportTarget.create(('192.168.1.10', 161)),
    ContextData(),
    0, 25,                     # non-repeaters, max-repetitions
    ObjectType(ObjectIdentity('1.3.6.1.2.1.2.2.1.10')),
    lexicographicMode=False        # ⚠️ 关键！否则一直走到 MIB 末尾
):
    if errorIndication or errorStatus:
        break
    for name, val in varBinds:
        print(f'{name.prettyPrint()} = {val.prettyPrint()}')

7.x API 的 4 个关键差异（4.x 用户必看）

项目4.x 老写法7.x 新写法
导入路径from pysnmp.hlapi import *from pysnmp.hlapi.v3arch.asyncio import *
调用方式next(getCmd(...))await get_cmd(...)
传输目标UdpTransportTarget((ip, 161))await UdpTransportTarget.create((ip, 161))
引擎释放不用管记得 engine.close_dispatcher()

官方资料（首选）

官网PySNMP 7 官网 ⭐ 首选高层 API 教程（asyncio） 文档PySNMP 库文档 GitHubPySNMP GitHub（examples 目录最重要） 实战实用 pysnmp 轮询指南（含 v3 和表格遍历）

自查

  • 能独立写出 GET 读一个 OID，并正确处理 errorIndication / errorStatus / varBinds 三个返回通道

树莓派 snmpd 配置（2 小时）

目标：把树莓派变成"真实的 SNMP 设备"，让电脑能 snmpget 到它。

# 1. 装 snmpd
sudo apt update && sudo apt install snmpd snmp -y

# 2. 备份原配置
sudo cp /etc/snmp/snmpd.conf /etc/snmp/snmpd.conf.bak

# 3. 编辑配置
sudo nano /etc/snmp/snmpd.conf

关键配置项：

# 监听所有网卡（默认只监听 127.0.0.1，这是最常见的坑！）
agentAddress udp:161

# 只读团体名（生产环境别用 public）
rocommunity public default

# 允许整个网段访问（按需改）
rocommunity public 192.168.1.0/24

sysLocation  "实验室"
sysContact  "你的邮箱"
# 4. 重启并设为开机自启
sudo systemctl restart snmpd
sudo systemctl enable snmpd

# 5. 本地验证
snmpwalk -v 2c -c public localhost .1.3.6.1.2.1.1

OID 配置文件设计（oid_config.json）

答辩要讲"配置驱动"的设计思想。

{
  "devices": [
    {
      "name": "raspberrypi-4b",
      "ip": "192.168.1.10",
      "port": 161,
      "version": "2c",
      "community": "public",
      "oids": {
        "sysName":    "1.3.6.1.2.1.1.5.0",
        "sysUpTime":  "1.3.6.1.2.1.1.3.0",
        "ifInOctets": "1.3.6.1.2.1.2.2.1.10",
        "ifOutOctets":"1.3.6.1.2.1.2.2.1.16"
      },
      "interval": 5
    }
  ]
}
