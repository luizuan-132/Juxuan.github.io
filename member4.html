02

ECharts 入门（核心，3-4 小时）

🔥 关键：离线 JS 文件文档明确要求下载离线 JS（赛场无外网，不能用 CDN！）。下载后放到项目的 static/ 目录，HTML 里引 <script src="/static/echarts.min.js"></script>。

最小可用例子

<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <title>网巡卫士 · 网络流量监控看板</title>
    <script src="/static/echarts.min.js"></script>
    <style>
        #chart { width: 100%; height: 500px; }
    </style>
</head>
<body>
    <h1>网络流量实时监控</h1>
    <div id="chart"></div>

    <script>
        // 1) 初始化图表
        const myChart = echarts.init(document.getElementById('chart'));

        // 2) 数据结构：时间序列
        const times = [];
        const inRates = [];
        const outRates = [];

        // 3) 初始配置
        const option = {
            title: { text: '实时流量 (Mbps)' },
            tooltip: { trigger: 'axis' },
            legend: { data: ['入站', '出站'] },
            xAxis: { type: 'category', data: times },
            yAxis: { type: 'value', name: 'Mbps' },
            series: [
                { name: '入站', type: 'line', smooth: true, data: inRates,
                  areaStyle: {}, itemStyle: { color: '#5470C6' } },
                { name: '出站', type: 'line', smooth: true, data: outRates,
                  itemStyle: { color: '#91CC75' } }
            ]
        };
        myChart.setOption(option);

        // 4) 抓数据 + 刷新（核心！）
        async function refresh() {
            try {
                const res = await fetch('/api/metrics/1?limit=30');  // 调队员3的接口
                const data = await res.json();     // [{ts, in_rate, out_rate}, ...]

                // 重新装配数据
                times.length = 0; inRates.length = 0; outRates.length = 0;
                data.reverse().forEach(d => {
                    times.push(d.ts);
                    inRates.push(d.in_rate);
                    outRates.push(d.out_rate);
                });

                // 5) 更新图表（setOption 增量更新，不会重建图表）
                myChart.setOption({ xAxis: { data: times }, series: [{ data: inRates }, { data: outRates }] });
            } catch (e) {
                console.error('获取数据失败', e);
            }
        }

        setInterval(refresh, 2000);   // 每 2 秒刷新一次 ← 文档要求的 setInterval
        refresh();                     // 页面一打开就先抓一次

        // 6) 窗口大小变化时自适应（必加，否则图表变形）
        window.addEventListener('resize', () => myChart.resize());
    </script>
</body>
</html>

必须掌握的三个 API（就这三个）

API作用备注
echarts.init(dom)初始化图表实例容器必须有宽高
chart.setOption(option)设置/更新配置默认是 merge 增量更新，不会销毁重绘，性能好
chart.resize()窗口变化时重算尺寸不加这个窗口一拉就变形

自查

  • setOption 更新数据时，为什么不用重新 init？（merge 增量更新，保留动画和状态）
  • setOption(option, true) 第二个参数什么意思？（notMerge，完全替换配置，切图表类型时用）
  • 为什么选折线图而不是柱状图？（流量是连续时间序列，折线能看出趋势和突变）
  • 数据点累积太多怎么办？（只保留最近 N 个点，如 30-60 个，用 shift() 挤掉旧的）

03

Flask-SocketIO 前端对接（进阶，2 小时）

文档说"WebSocket 或 轮询"——轮询最简单，先做通轮询拿分，有时间再上 WebSocket。

<!-- ⚠️ 必须用 Socket.IO 客户端库，不能用浏览器原生 WebSocket！ -->
<script src="https://cdn.socket.io/4.7.5/socket.io.min.js"></script>
<!-- 离线版：下载 socket.io.min.js 放到 static/ 目录 -->
const socket = io();   // 自动连接当前域名

socket.on('connect', () => console.log('已连接'));

// 接收后端主动推送的数据（比轮询实时）
socket.on('metrics_update', (data) => {
    times.push(data.ts);
    inRates.push(data.in_rate);
    outRates.push(data.out_rate);
    // 只保留最近 30 个点
    if (times.length > 30) { times.shift(); inRates.shift(); outRates.shift(); }
    myChart.setOption({
        xAxis: { data: times },
        series: [{ data: inRates }, { data: outRates }]
    });
});

// 接收告警推送
socket.on('new_alert', (alert) => {
    // 弹出告警条 / 图表上打标记
    console.log('新告警:', alert);
});
⚠️ 常见坑 ① Socket.IO 版本必须前后端匹配（后端 Flask-SocketIO 5.x ↔ 前端 Socket.IO 4.x）
② 后端必须用 socketio.run(app) 而不是 app.run()，否则 WebSocket 不通
③ 不能用原生 new WebSocket()，必须用 Socket.IO 客户端
④ 赛场离线 → socket.io.min.js 也要提前下载放到 static/

轮询 vs WebSocket 怎么选

轮询（setInterval + fetch）WebSocket（Flask-SocketIO）
实现难度⭐ 简单⭐⭐⭐ 较复杂
实时性2 秒延迟毫秒级
服务器压力每秒都有请求长连接，压力小
考场稳定性高（HTTP 成熟）中（版本不匹配易挂）
建议先做这个拿分有时间再上

04

看板页面设计建议（你要讲的板块）

答辩第 10-20 分钟：切换看板视图。建议设计 3 个视图。

1. 总览视图

所有设备的健康状态卡片（绿/黄/红）。

2. 实时流量视图

折线图动态刷新 + 告警标记点。

3. 告警历史视图

告警列表 + 历史曲线。

视觉建议

  • 深色科技风背景（#0F1419 之类），配亮色曲线 → 投屏效果好
  • 顶部放大字号的关键指标（当前速率 / 告警数 / 在线设备数）
  • 告警用颜色区分：info=蓝、warning=黄、critical=红
⚠️ 注意本项目是网络监控，不是股票。流量高低没有"涨红跌绿"的语义，别套用红绿涨跌规则，用通用告警色（红=异常、绿=正常）就好。
